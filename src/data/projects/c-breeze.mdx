## Overview

C-Breeze is an autonomous IoT cooling system that activates a fan when a nearby person is detected. It connects computer vision on a laptop with an ATmega328P-based controller, ultrasonic proximity sensing, and a real-time browser dashboard.

## Engineering focus

- Built AVR C firmware to drive an L293D motor driver and read an HC-SR04 ultrasonic sensor.
- Used an OpenCV vision process to identify a nearby person and send control signals over UART.
- Added automatic and manual control modes, including a 50 cm proximity threshold and 5 cm hysteresis to avoid rapid fan switching.
- Streamed distance, presence, fan state, and operating mode to a web dashboard through a Node.js and WebSocket backend.
- Included timeout and serial-error handling so the system safely degrades if a sensor or camera connection fails.

## System design

The project keeps detection, control, and visualization separate: Python handles camera input, the AVR handles deterministic hardware control, and the web layer exposes status and manual commands. This makes the prototype easier to validate and extend without mixing real-time firmware concerns into the dashboard.

## Overview

SecureBoot-AVR is a bare-metal bootloader project for the ATmega328P. It establishes a verification step before application code runs, keeping the device in recovery mode when a firmware image does not pass validation.

## Engineering focus

- Defined a bootloader and application memory layout for an Arduino Uno-class device.
- Added SHA-256 integrity checks and an Ed25519 verification interface for signed firmware.
- Used EEPROM-backed counters for anti-rollback protection.
- Included UART communication with CRC validation and a host-side firmware signing tool.
- Kept the build portable with CMake and an AVR-GCC toolchain.

## Scope note

The repository documents its Ed25519 implementation as an integration placeholder. It is a learning-focused secure-boot architecture, not a production security claim.

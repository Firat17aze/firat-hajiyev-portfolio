## Overview

AVR Zero-Alloc RTOS is a cooperative scheduler designed for the constraints of an ATmega328P. The project favors predictable memory use and transparent low-level control over framework dependencies.

## Engineering focus

- Built task scheduling in C using static memory allocation.
- Worked directly with AVR registers rather than Arduino abstractions.
- Kept the runtime dependency-free to make resource costs explicit.
- Explored the design tradeoffs behind deterministic, memory-constrained embedded software.

## Why it matters

This project demonstrates the kind of design discipline needed when RAM, timing, and control flow are all first-class engineering constraints.

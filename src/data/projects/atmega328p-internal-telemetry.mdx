## Overview

This project reads the ATmega328P's internal temperature sensor and supply-voltage signals without relying on external sensor modules or Arduino libraries.

## Engineering focus

- Configured AVR ADC registers to access the internal temperature channel.
- Measured supply voltage through the microcontroller's internal reference path.
- Applied a Kalman filter to stabilize noisy readings.
- Exposed device status through a 9600-baud UART command interface.

## Design takeaway

The project combines register-level peripheral control, filtering, and a practical diagnostic interface in a compact embedded system.
